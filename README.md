# Todo Lists Web Application

A simple and intuitive web-based Todo List application that allows users to create, manage, and track their tasks efficiently. Built with vanilla JavaScript, HTML, and CSS, this app provides a clean and responsive interface for organizing daily tasks.

## Features

- **Add Tasks**: Easily add new tasks with a user-friendly input field.
- **Mark as Complete**: Check off completed tasks with a strikethrough effect.
- **Delete Tasks**: Remove unwanted tasks with a single click.
- **Persistent Storage**: Tasks are saved locally using browser's localStorage, ensuring data persists across sessions.
- **Responsive Design**: Optimized for various screen sizes using Bootstrap framework.
- **Save Functionality**: Manually save the current state of the todo list.

## Technologies Used

- **HTML5**: Structure and markup of the application.
- **CSS3**: Styling and layout, including custom fonts and responsive design.
- **JavaScript (ES6)**: Core functionality, DOM manipulation, and localStorage integration.
- **Bootstrap 4.5.2**: CSS framework for responsive grid system and components.
- **FontAwesome**: Icons for delete functionality.
- **Google Fonts**: Custom fonts for enhanced typography.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/gagan2105/todo-lists-web-application.git
   ```

2. Navigate to the project directory:
   ```bash
   cd todo-lists-web-application
   ```

3. Open `todoslist.html` in your preferred web browser.

No additional setup or dependencies are required as the app runs entirely in the browser.

## Usage

- Enter a task in the input field and click "Add" to create a new task.
- Check the checkbox next to a task to mark it as completed.
- Click the trash icon to delete a task.
- Click "Save" to persist the current list to localStorage.
